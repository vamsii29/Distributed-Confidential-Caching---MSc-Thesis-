# Distributed Confidential Caching

A research project exploring distributed confidential caching using Trusted Execution Environments (TEEs).

## Overview

This project investigates confidential distributed caching architectures leveraging hardware-assisted memory protection.

The implementation aims to support:

- AMD SEV-SNP
- Intel SGX
- Distributed caching
- Performance evaluation across different cluster configurations

## Technology Stack

- Rust
- Trusted Execution Environments (TEEs)
- Distributed Systems

## Project Status

Under active development as part of an MSc thesis.
